# Changelog

## 1.2.1

- Branded drag-to-install DMG with a mint gradient, Retina artwork, large icon targets, and an Applications shortcut.
- Fixed Finder window layout and custom volume icon.
- License and installation notes bundled inside the app, leaving two visible installer items.
- Expanded README with download, installation, first-launch, upgrade, ZIP, checksum, and usage instructions.
- Reproducible packaging with pinned isolated tools and verification of the mounted installer.

## 1.2.0

- Living theme animations and calmer break palettes.
- Floating mini timer sharing the current session, with remembered position, session/theme menu, and keyboard controls.
- Reduce Motion support and a living-effects toggle.

## 1.1.0

- Distinct Synthwave and Cyberpunk layouts, typography, controls, and progress displays.

## 1.0.0

- Native universal macOS Pomodoro app with three gradient themes, editable session lengths, pause/resume, saved state, session counter, menu bar controls, completion sound, and a ten-second demo.
